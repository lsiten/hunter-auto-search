# 脉脉运行环境要求

> 本文档列出使用 Hermes Agent 进行脉脉自动化搜索的前置条件和运行环境要求。

---

## 系统要求

### 1. Python 环境
- **Python 版本**: 3.10+
- **必需包**:
  - `pydantic>=2.0` - 数据验证和模型定义
  - `loguru` - 日志记录
  - `click` - 命令行界面

**安装命令:**
```bash
pip install -e /path/to/hunter-auto-search
# 或
pip install pydantic loguru click
```

### 2. Hermes Agent 环境
- **Hermes 版本**: 支持 MCP Chrome 工具的版本
- **必需 MCP 工具**:
  - `mcp_chrome_navigate` - 页面导航
  - `mcp_chrome_click_element` - 点击元素
  - `mcp_chrome_fill_or_select` - 表单输入
  - `mcp_chrome_get_web_content` - 获取页面内容
  - `mcp_chrome_javascript` - 执行 JavaScript
  - `mcp_chrome_screenshot` - 页面截图
  - `mcp_chrome_read_page` - 读取可访问性树

## 脉脉账号要求

### 1. 账号类型
- **推荐**: 脉脉会员账号 (VIP)
  - 无搜索次数限制
  - 可以查看完整档案
  - 解锁更多筛选条件
  - 可查看更多联系方式

- **免费账号**:
  - ⚠️  每天搜索次数有限 (~50 次)
  - ⚠️  查看档案有限制
  - ⚠️  联系方式查看受限

### 2. 登录方式

#### 方式一: 手机号验证码登录 (推荐)
```
1. 输入手机号
2. 点击获取验证码
3. 输入收到的短信验证码
4. 点击登录
```

#### 方式二: 扫码登录
```
1. 切换到二维码登录标签
2. 使用脉脉 App 扫码
3. 在 App 上确认登录
```

### 3. 账号安全建议
```text
✅ 建议使用专用账号进行自动化操作
✅ 开启两步验证增强安全性
✅ 避免在常用个人账号上进行高频操作
✅ 定期检查账号活动记录
✅ 建议绑定微信，提高账号安全性
⚠️  不要在短时间内进行大量搜索（防风控）
```

### 1. 网络连接
- **要求**: 能够稳定访问脉脉服务器
- **推荐延迟**: < 100ms (国内网络即可)
- **最低带宽**: 2Mbps

### 2. 特殊网络要求
```text
脉脉服务器在国内，无需翻墙
建议使用稳定的国内网络
避免使用公共 WiFi 进行敏感操作
```

### 3. 防火墙/安全软件
```text
需要放行的域名:
- *.maimai.cn
- *.maimai.com
- static.maimai.cn (静态资源)
```

## Cookie 存储要求

### 1. 存储位置
```
cookies/
└── maimai_<account>.json    # 每个账号独立文件
```

### 2. Cookie 结构
```json
{
  "account": "default",
  "platform": "maimai",
  "created_at": "2026-05-11 23:00:00",
  "cookies": [
    {
      "name": "access_token",
      "value": "...",
      "domain": ".maimai.cn",
      "path": "/",
      "expires": 1234567890,
      "httpOnly": true,
      "secure": true
    }
  ]
}
```

### 3. 关键 Cookie 字段
| Cookie 名称 | 作用 | 重要性 |
|------------|------|--------|
| `access_token` | 访问令牌 | ⭐⭐⭐ 必需 |
| `uid` | 用户 ID | ⭐⭐⭐ 必需 |
| `sess` | 会话 ID | ⭐⭐ 推荐 |

### 4. Cookie 有效期
- **正常有效期**: 约 7-30 天
- **建议**: 每周检查一次 Cookie 状态
- **续期方式**: 重新登录获取新 Cookie

## 搜索频率限制

### 1. 免费账号限制 (参考)
```text
- 每日搜索次数: ~50-100 次
- 每日查看档案: ~50-100 个
- 每小时请求: 建议 < 30 次
```

### 2. VIP 账号限制 (参考)
```text
- 每日搜索次数: 500-1000 次
- 每日查看档案: 300-500 个
- 每小时请求: 建议 < 100 次
```

### 3. 防风控最佳实践
```text
✅ 请求间隔: 3-8 秒/次
✅ 批量操作: 每采集 30 条暂停 5 分钟
✅ 工作时间: 模拟人类作息 (9:00-18:00)
✅ 随机延迟: 在固定间隔上增加 ±50% 随机波动
✅ 页面滚动: 模拟真实用户浏览行为
✅ 鼠标移动: 模拟真实用户鼠标轨迹 (如有能力)

❌ 不要: 在 1 分钟内发送超过 20 个请求
❌ 不要: 24 小时不间断运行
❌ 不要: 完全固定的请求间隔
❌ 不要: 深夜进行大量操作
```

## 浏览器环境要求

### 1. 推荐浏览器
- **Chrome / Chromium**: 首选，MCP 工具原生支持
- **Edge**: 基于 Chromium，兼容性良好


```text

│ 特性          │ 无头模式       │ 有头模式       │

│ 速度          │ 快            │ 慢            │
│ 可视化调试    │ ❌ 不可用     │ ✅ 可用       │
│ 二维码登录    │ ❌ 困难       │ ✅ 易处理     │
│ 滑块验证码    │ ❌ 困难       │ ✅ 易处理     │
│ 推荐场景      │ 稳定批量采集   │ 登录和调试   │
```

## 常见环境问题

### Q1: 脉脉页面加载缓慢
```text
检查网络连接 (国内网络通常很快)
清除浏览器缓存
尝试刷新页面
```

### Q2: Cookie 很快失效
```text
减少操作频率，模拟人类行为
避免多设备同时登录同一账号
脉脉风控较严格，注意操作节奏
```

### Q3: 页面元素找不到
```text
确认网络连接正常，页面完全加载
脉脉页面结构更新较快，检查选择器是否需要更新
可能需要登录后才能看到完整页面内容
```

## 特殊注意事项

### 脉脉反爬特点
```text
1. 滑块验证码: 登录和搜索时可能出现
2. 频率限制: 免费账号每日限制明显
3. 行为分析: 对异常操作模式敏感
4. IP 监控: 短时间大量请求会触发验证

建议策略:
- 白天工作时间段操作
- 操作间隔随机化
- 每次操作后滚动页面
- 模拟真实用户的浏览行为
```
