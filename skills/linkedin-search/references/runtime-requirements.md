# 领英运行环境要求

> 本文档列出使用 Hermes Agent 进行领英自动化搜索的前置条件和运行环境要求。

---

## 系统要求

### 1. Python 环境
- **Python 版本**: 3.10+
- **必需包**:
  - `pydantic>=2.0` - 数据验证和模型定义
  - `loguru` - 日志记录
  - `click` - 命令行界面

**安装命令:**
```bash
pip install -e /path/to/hunter-auto-search
# 或
pip install pydantic loguru click
```

### 2. Hermes Agent 环境
- **Hermes 版本**: 支持 MCP Chrome 工具的版本
- **必需 MCP 工具**:
  - `mcp_chrome_navigate` - 页面导航
  - `mcp_chrome_click_element` - 点击元素
  - `mcp_chrome_fill_or_select` - 表单输入
  - `mcp_chrome_get_web_content` - 获取页面内容
  - `mcp_chrome_javascript` - 执行 JavaScript
  - `mcp_chrome_screenshot` - 页面截图
  - `mcp_chrome_read_page` - 读取可访问性树

## 领英账号要求

### 1. 账号类型
- **推荐**: 领英高级账号 (Premium)
  - 无搜索次数限制
  - 可以查看完整档案
  - 解锁更多筛选条件

- **免费账号**:
  - ⚠️  每月搜索次数有限（约 100-300 次）
  - ⚠️  部分高级筛选不可用
  - ⚠️  查看档案受限于 3 度人脉

### 2. 登录方式
- **账号密码登录** (推荐)
  - 用户名：邮箱/手机号
  - 密码：领英登录密码

- **扫码登录**
  - 在登录页面选择"使用二维码登录"
  - 使用领英 App 扫码

### 3. 账号安全建议
```text
✅ 建议使用专用账号进行自动化操作
✅ 开启两步验证增强安全性
✅ 避免在常用个人账号上进行高频操作
✅ 定期检查账号活动记录
⚠️  不要在短时间内进行大量搜索（防风控）
```

## 网络环境要求

### 1. 网络连接
- **要求**: 能够稳定访问领英国际站
- **推荐延迟**: < 200ms
- **最低带宽**: 2Mbps

### 2. 代理/VPN 设置
如果无法直接访问领英：
```text
# 确保系统代理已正确配置
# Hermes Agent 会继承系统代理设置

# 验证代理是否工作
curl -I https://www.linkedin.com
# 应返回 HTTP/2 200
```

### 3. 防火墙/安全软件
```text
需要放行的域名:
- *.linkedin.com
- *.licdn.com (领英 CDN)
- *.linkedin.cn (领英中国，如使用)
```

## Cookie 存储要求

### 1. 存储位置
```
cookies/
└── linkedin_<account>.json    # 每个账号独立文件
```

### 2. Cookie 结构
```json
{
  "account": "default",
  "platform": "linkedin",
  "created_at": "2026-05-11T23:00:00",
  "cookies": [
    {
      "name": "li_at",
      "value": "...",
      "domain": ".linkedin.com",
      "path": "/",
      "expires": 1234567890,
      "httpOnly": true,
      "secure": true
    }
  ]
}
```

### 3. 关键 Cookie 字段
| Cookie 名称 | 作用 | 重要性 |
|------------|------|--------|
| `li_at` | 登录状态认证 | ⭐⭐⭐ 必需 |
| `JSESSIONID` | 会话 ID | ⭐⭐⭐ 必需 |
| `lidc` | 负载均衡 | ⭐⭐ 推荐 |
| `bcookie` | 浏览器标识 | ⭐⭐ 推荐 |

### 4. Cookie 有效期
- **正常有效期**: 约 30-90 天
- **建议**: 每周检查一次 Cookie 状态
- **续期方式**: 重新登录获取新 Cookie

## 搜索频率限制

### 1. 免费账号限制 (参考)
```text
- 每月搜索次数: 约 100-300 次
- 每日查看档案: 约 100 个
- 每小时请求: 建议 < 50 次
```

### 2. Premium 账号限制 (参考)
```text
- 每月搜索次数: 无明确限制
- 每日查看档案: 约 1000+ 个
- 每小时请求: 建议 < 200 次
```

### 3. 防风控最佳实践
```text
✅ 请求间隔: 2-5 秒/次
✅ 批量操作: 每采集 50 条暂停 5 分钟
✅ 工作时间: 模拟人类作息，避免深夜操作
✅ 随机延迟: 在固定间隔上增加 ±30% 随机波动
✅ 页面滚动: 模拟真实用户浏览行为
✅ 鼠标移动: 模拟真实用户鼠标轨迹 (如有能力)

❌ 不要: 在 1 分钟内发送超过 20 个请求
❌ 不要: 24 小时不间断运行
❌ 不要: 完全固定的请求间隔
```

## 数据存储要求

### 1. 输出目录结构
```
output/
├── linkedin_search_20260511_230000.json    # JSON 原始数据
├── linkedin_search_20260511_230000.csv     # CSV 表格数据
├── linkedin_detail_12345.json              # 单个候选人详情
└── ...
```

### 2. 存储容量估算
```text
每条候选人数据: ~2-5 KB (JSON)
100 条候选人: ~0.5 MB
1,000 条候选人: ~5 MB
10,000 条候选人: ~50 MB

建议预留空间: >= 1 GB
```

### 3. 备份建议
```text
✅ 每天备份 Cookie 文件
✅ 重要搜索结果多副本存储
✅ 定期导出 CSV 进行离线分析
✅ 考虑云存储同步 (Git, OneDrive 等)
```

## 浏览器环境要求

### 1. 推荐浏览器
- **Chrome / Chromium**: 首选，MCP 工具原生支持
- **Edge**: 基于 Chromium，兼容性良好

### 2. 浏览器设置
```text
✅ 启用 JavaScript
✅ 允许 Cookie 和网站数据
✅ 禁用弹出窗口拦截器 (针对领英域名)
✅ 建议: 禁用自动翻译功能
```

### 3. 无头模式 vs 有头模式
```text
┌─────────────┬─────────────────┬─────────────────┐
│ 特性        │ 无头模式         │ 有头模式         │
├─────────────┼─────────────────┼─────────────────┤
│ 资源占用    │ 低              │ 高              │
│ 速度        │ 快              │ 慢              │
│ 可视化调试  │ ❌ 不可用       │ ✅ 可用         │
│ 验证码处理  │ ❌ 困难         │ ✅ 易处理       │
│ 推荐场景    │ 稳定批量采集    │ 登录和调试     │
└─────────────┴─────────────────┴─────────────────┘
```

### 1. 界面语言

```text
- 美国 IP: 显示全球用户

- 欧洲 IP: 符合 GDPR 隐私保护
```

## 常见环境问题

### Q1: 领英页面加载缓慢
```text
检查网络延迟和带宽
尝试使用更接近领英服务器的代理
```

### Q2: Cookie 很快失效
```text
减少操作频率，模拟人类行为
避免多设备同时登录同一账号
考虑使用固定 IP 地址
```

### Q3: 页面元素找不到
```text
确认领英界面语言为英语
检查选择器是否需要更新
页面可能还在加载中，增加等待时间
```
